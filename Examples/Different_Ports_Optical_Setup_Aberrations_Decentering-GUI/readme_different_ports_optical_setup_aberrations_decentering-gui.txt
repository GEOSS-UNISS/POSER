This scene includes a GUI to interactively change the optical parameters such as the position of the entrance pupil EP.
Usage:

1) Allow the execution of the script
2) on the left 3D viewport set the viewport shading to "Material Preview" or "Rendered" 
3) interact using the parameters available in the pane POSER-PORTS_COMPARISON switching between the different scenes dedicated to Flat, Dome and Cylinder aberrations
4) results are visible on the right 3D viewport placed in 2D view from the top

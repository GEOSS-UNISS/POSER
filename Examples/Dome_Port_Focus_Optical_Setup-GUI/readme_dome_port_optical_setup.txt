This scene includes a GUI to interactively change the optical parameters that influence focussing, depth of field and aberrations.
Practictionners can experiment with the virtual image formation, Petzval curvature and other optical aberrations when using a dome port underwater.

1) Allow the execution of the script
2) on the left 3D viewport set the viewport shading to "Material Preview" or "Rendered" 
3) interact using the parameters available in the pane POSER-DOME_PORT_SETUP. 
	For example:
	3.1) Make sure that the depth of field is enabled within the pane
	3.2) Modify the focusing distance in cm to be approximately three times the dome radius (typical distance of the virtual image)
	3.3) Check the amount of Petzval curvature (different focus in the middle and at the border near the corners - use the specific buttons under camera view navigation in the pane. Petzval curvature depends mainly on port size, experiment with port size byu using the scale factor.
	3.4) For the specified dome adjust the aperture value to modify the the depth of field and have the entire image in focus. Experiment with different sensor formats (with the same aperture value smaller sensors have larger depth of field)
4) results are visible on the right 3D viewport placed in 2D view from the top
